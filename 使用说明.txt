视频下载器 · 使用说明
==================================================

这是什么
  一个跑在你自己电脑上的网页程序：把视频页面的链接粘进去，解析出真实清晰度，
  直接在浏览器里下载成 mp4 文件。不装扩展、不注册账号、不上传任何数据。

怎么打开
  双击桌面上的「视频下载器」。
  黑色命令行窗口会自动打开，同时弹出浏览器页面 http://127.0.0.1:8791
  —— 那个黑窗口就是服务本身，关掉它服务就停了。

怎么用
  1) 复制视频播放页的链接（浏览器地址栏里那条）
  2) 粘到输入框，点「解析」
  3) 下方出现封面和清晰度按钮，点你要的那档
  4) 任务卡里进度跑完，点「下载到本机」存到浏览器下载目录，
     或点「打开文件夹」直接看文件（存在 downloads 子目录里）

浏览器扩展（刷到就想下的时候用）
  装一次：双击「安装扩展.bat」，按弹出的三步在 Chrome 里加载 extension 文件夹。
  之后刷到任何视频，点工具栏上的「视频下载器」图标：
    · 图标上的数字 = 这一页已经识别到几个视频
    · 点「扫描本页视频」会把页面播放器和后台加载的视频流都列出来
    · 每条右边点「下载」，视频交给本地工具保存（先双击桌面快捷方式把工具启动）
  扩展会自动带上你这个站点在浏览器里的最新 cookie，所以抖音这类
  「需要新鲜 cookie」的站，用扩展下比在网页里粘链接更稳。
  抖音那种地址里没有 .mp4 后缀的视频，扩展是按响应类型识别的，也能抓到。

整页扫描（一个页面里有很多视频时用）
  输入页面地址，点「整页扫描」。工具会真把这个页面打开一遍，把页面里能下到的
  视频全部列出来：页面内播放器、HLS 流、后台加载的 mp4 都会抓到，
  每条显示 类型 / 清晰度 / 时长 / 地址，点右边「下载」按最高画质下。
  扫描会弹出一个工具自带的 Chrome 窗口（配置存在 chrome-profile 目录），
  那个窗口可以最小化，别关；真关了下次扫描会自动重开。
  要下抖音 / 小红书这类必须登录的站，先在那个窗口里登录一次，之后一直有效。
  扫不到东西时列表下方会写原因（页面被拦 / 要登录 / 视频要点播放才加载）。

支持的站点
  底层是 yt-dlp，支持一千多个站点：抖音、小红书、B站、快手、YouTube、
  Twitter/X、Instagram、Vimeo、微博、TED 等。
  央视网 / 央视频页面（app.cctv.com、tv.cctv.com）内置了专门适配，
  能直接解析出真实流地址和节目名，不用自己找 m3u8。
  纯直链 mp4 / m3u8 也能直接下。

三个需要知道的点
  【海外站点】YouTube / X 这些连不上时，勾上「走本机代理」（默认会自动勾）。
  【抖音 / 小红书 / B站】这些站点要登录才给视频流，所以需要导入你自己的登录态：
      1. 完全退出 Chrome（右上角关闭不够，任务栏托盘里的也要退）
      2. 点页面上「抓取登录态」
      3. 看到「登录态已导入 N 条」就好了，之后再也不用重复
    登录态只存在本目录的 cookies.txt 里，不会发给任何服务器。
    Chrome 开着的时候点抓取会提示你关闭，这是 Windows 文件锁，不是毛病。
  【书签一键下载】页面底部有个「⬇ 下载本页视频」按钮，拖到浏览器书签栏。
    以后在任何视频页面点这个书签，页面会自动送进工具并开始解析。

常见问题
  · 解析报「不支持的链接」→ 粘的是列表页/首页，请打开视频播放页再复制
  · 解析超时 → 海外站点勾代理；抖音类站点先导入登录态
  · 打不开页面 → 黑窗口是不是被关了？重新双击桌面快捷方式
  · 端口冲突 → 程序已在运行时再双击，会直接打开浏览器，不会起第二个
