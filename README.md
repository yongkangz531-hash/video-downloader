# 视频下载器（本地网页版 + Chrome 扩展）

在自己电脑上跑一个网页，粘链接就能把视频下成 mp4；配一个 Chrome 扩展，刷到什么点一下就能识别。
全部本地运行：不注册、不上传、不经过任何第三方服务器。

## 三种用法

### 1. 便携版（换台电脑双击就能跑）

下载 Release 里的 `视频下载器-便携版.zip`，解压到任意目录，双击 `启动下载器.bat`。
包里已经带了 Python 和 yt-dlp，不需要装任何东西（只要系统里有 Chrome）。

### 2. 源码运行（本机已有 Python）

```bash
python app.py
# 浏览器打开 http://127.0.0.1:8791
```

第一次运行如果没有 yt-dlp，程序会自动下载到 `tools/yt-dlp.exe`。

### 3. Chrome 扩展（刷到什么下什么）

扩展装一次：`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选 `extension` 目录。
之后点工具栏图标，能看到当前页识别到的所有视频，选一条点「下载」。
扩展会把浏览器里该站点的最新 cookie 一并交给本地下载器，所以抖音这类站点也能下。

## 能干什么

- 单条解析：粘视频页链接 → 选清晰度 → 下载
- 整页扫描：一个页面里多个视频，全部列出来挑着下
- 自动回退嗅探：站点自己的解析器不认（例如抖音要新鲜 cookie）时，自动打开页面抓真实播放流
- 央视适配：`app.cctv.com` / `tv.cctv.com` 直接取真实 m3u8 和节目名
- 海外站点：勾「走本机代理」（默认 127.0.0.1:7897，可用 `VD_PROXY` 覆盖）
- 书签一键：页面底部的书签拖到工具栏，任何视频页点一下就送进来解析

## 目录

```
app.py              主程序（单文件，只用标准库）
extension/          Chrome 扩展（MV3）
启动下载器.bat       双击启动（自动找 Python）
安装扩展.bat         打开扩展页和目录
make_portable.py    打便携版 zip
tools/              yt-dlp / ffmpeg 放这里（缺失时自动下载 yt-dlp）
downloads/          下载产物
cookies.txt         扩展导入的登录态（勿外传）
```

## 可选：ffmpeg

HLS（.m3u8）合并需要 ffmpeg；只下直链 mp4 不需要。
没有的话程序会在启动横幅里提示。Windows 上装：

```bash
winget install Gyan.FFmpeg
```

或者把 `ffmpeg.exe` 放进 `tools/` 目录，程序会自动认。

## 环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `VD_PORT` | 服务端口 | 8791 |
| `VD_PROXY` | 代理地址 | http://127.0.0.1:7897 |

## 更新下载引擎

yt-dlp 更新很勤，站点变了先更新它：

```bash
# 便携版
tools\yt-dlp.exe -U
```

## 常见问题

**解析报「不支持的链接」**　粘的是列表页/首页，请打开视频播放页再复制。

**抖音解析失败**　会自动改用页面嗅探；嗅探到的地址有时效，解析完尽快点下载。

**HLS 下载完是 0 字节 / 合成失败**　装 ffmpeg（见上）。

**扩展点下载提示连不上**　本地工具没启动，先双击 `启动下载器.bat`。
